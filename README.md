# Inbox Guard Switzerland

We help organisations move their domains safely from **DMARC p=none to p=reject** – the point where mailbox providers reject forged mail in their name. Plus **MTA-STS** for encrypted delivery.

- Free DMARC check, no sign-up: https://www.igs.ch/?p=check
- Free tools: read a DMARC report, count SPF lookups, build a DMARC record: https://www.igs.ch/?p=tool
- Knowledge base (DE/FR/IT/EN): https://www.igs.ch/?p=wissen

Operated in Switzerland. No mail content, no recipient addresses.
